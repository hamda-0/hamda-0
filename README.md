## 👋 About Me

```text
Mobile App Developer · 2+ years · React Native & Flutter · Node.js backend
```

I build and maintain **production mobile apps** for real clients. My work has covered real-time location tracking, Stripe payments, Agora video calling, push notifications, social login, and multilingual RTL interfaces. I also own the release path: **EAS builds, App Store and Play Store submission**, and keeping live apps healthy after launch.
